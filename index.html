Process spine · layout template

◆ DESIGN SYSTEM // PROCESS SPINE // TEMPLATE

Stages define work.
Gates define decisions.

A reusable layout for any staged, gated process. Stages are circles because they are periods of work. Gates are diamonds because they are decisions. Content is filled in from the organisation's own system of record, not from this file.

Switch the gate set to see which decisions apply under each variant.
